# 경안고등학교 교외체험학습 스마트 작성

2026학년도 학교장허가 교외체험학습 신청서, 결과보고서 및 별지의 작성·출력을 지원합니다. 설치나 빌드가 필요 없는 정적 웹앱입니다.

## GitHub Pages에 올리기

1. ZIP을 풀고 `index.html`, `style.css`, `*.mjs`, `calendar.json`, `assets/`, `.nojekyll`, `README.md`를 저장소의 `main` 브랜치 최상위에 올립니다. ZIP 파일이나 압축을 푼 바깥 폴더 대신 위 파일과 폴더를 올립니다. 웹 업로드 화면에서 `.nojekyll`이 누락되면 **Add file → Create new file**에서 해당 이름으로 만듭니다.
2. **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 고르고 **main / (root)**를 선택한 뒤 **Save**를 누릅니다.
3. **Settings → Pages**에 표시된 주소에 접속합니다. 학생·학부모용 화면과 교사용 화면에서 양식 다운로드와 미리보기를 확인합니다.

[GitHub Pages 게시 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

배포 전 PC에서 확인하려면 압축을 푼 폴더에서 `python -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`으로 들어갑니다. 모듈과 PDF 양식을 읽으려면 HTTP 주소를 사용해야 합니다.

## 학생·학부모

1. **신청서**에 인적 사항, 체험 일정과 계획을 입력합니다. **답사·견학 활동**을 선택하면 세부 목적에 **대학 탐방**이 표시됩니다. 보호자·인솔자는 각자 입력하거나 보호자 정보를 인솔자란에 복사할 수 있습니다.
2. **미리보기 → 인쇄** 또는 **PDF 내려받기**를 사용합니다. 서명은 해당자가 화면에서 그리거나 종이에 직접 할 수 있습니다. PDF 생성 후 담임교사를 통해 최종 허가를 확인합니다.
3. **결과보고서**에서 **신청서의 일정과 동반자 불러오기**를 선택하거나 따로 작성합니다. 학생이 체험일마다 직접 기록을 입력합니다. 첫날은 서식 2, 이후 날짜는 별지에 배치됩니다. 활동 증빙으로 JPG·PNG·PDF를 첨부합니다. 국외 체험은 날짜를 확인할 수 있는 사본을 첨부하고 체크합니다.

## 담임교사 일괄 작성

1. **교사 · 학급 일괄 작성 → 엑셀 양식**에서 30행 입력 양식을 받습니다. 학습형태를 먼저 선택하면 세부목적 목록이 바뀝니다. Excel에서 학습형태를 바꿀 때는 이미 입력한 세부목적을 지우고 다시 선택합니다.
2. `명단` 시트 또는 CSV 첫 행에 **학년, 반, 번호, 성명**이 있어야 합니다. 기존 명렬표도 처음 네 필수 열의 머리글이 맞으면 불러올 수 있습니다. UTF-8 및 CP949 CSV와 XLSX를 지원합니다. CSV에서는 불러온 뒤 웹 편집표의 드롭다운을 사용합니다.
3. 웹 편집표에서 드롭다운을 바꾸고, 학생 이름 버튼을 눌러 일정·인솔자·계획·기록과 첨부를 보완합니다. 입력 원본 학생을 열고 표에서 대상을 체크한 뒤 **선택 학생의 공통 내용 복사**를 누르면 해당 서식의 일정·목적지·계획 등 공통 항목을 복사합니다.
4. 표에서 대상자를 체크하고 **현재 서식 ZIP** 또는 **두 서식 ZIP**을 누릅니다. 오류 메시지에 표시된 학생과 항목을 수정한 후 다시 생성합니다. 보고서 본문과 증빙은 학생별로 입력합니다.

## 적용 규정과 학사일정

- 이번 신청은 최대 5일, 이전 사용분을 포함한 학년도 누적은 20일까지입니다. 이전 사용분은 이번 신청 전까지의 실제 일수를 입력합니다. 반일은 당일 수업에 참여하고 체험시간이 4시간 미만일 때 0.5일입니다.
- 신청 마감은 시작일 3일 전, 보고서 마감은 종료일 3일 후로 달력 날짜 기준입니다. 신청서 작성일이 마감보다 늦으면 출력을 막습니다. 보고서 작성일이 마감보다 늦으면 담임교사 확인 안내를 표시하고 보고서는 출력할 수 있습니다. 실제 제출일은 학교에서 확인합니다.
- 토·일요일, 기본 공휴일, 등록한 휴업일을 인정 일수에서 뺍니다. 2026학년도 2학기 1차 정기시험 2026-10-12~16은 제공된 교내 감독표를 기준으로 기본 불허기간에 포함했습니다. 성적처리 완료일, 나머지 시험·방학·재량휴업·방학식·종업식 날짜는 학교의 확정 일정에 따라 등록합니다. 특히 3학년 2학기는 1차 정기시험 이후 성적처리 완료일까지의 기간을 등록합니다.
- **학년별 불허기간·휴업일 설정**에서 전체 또는 학년별로 기간을 추가합니다. 같은 날이면 시작일과 종료일에 같은 날짜를 넣습니다. `불허`는 일정과 겹치는 신청서의 출력을 막고, `휴업`은 해당 날짜를 일수와 보고서 체험일에서 제외합니다.
- 설정은 현재 브라우저에 저장됩니다. 학교 공통 설정은 **일정 JSON 내려받기**로 저장한 뒤 저장소의 `calendar.json`을 교체해 공유합니다. 기존 브라우저 설정이 있는 경우 새 JSON을 직접 가져옵니다. Excel은 기본 주말·공휴일로 계산하고 웹앱이 학교 설정을 적용해 다시 계산합니다.
- 가정학습은 감염병 위기경보 심각 단계 확인을 요구합니다. 일반 서식에 기본 체크 항목이 없어 해당 학습형태를 별도로 기입합니다.

## 개인정보 및 원본 양식

입력 내용, 명단, 서명, 첨부는 브라우저 탭 안에서 처리합니다. 서버 전송·자동 백업 기능이 없습니다. 새로고침하면 작성 내용이 지워지며 내려받은 PDF와 ZIP은 기기에 남습니다. 학사일정에는 일정 정보만 입력하며, 실제 명단·서명·증빙·작성 PDF는 GitHub에 올리지 않습니다.

기존 Work 코드와 양식 PDF를 재사용했습니다. 첨부 한글 원본을 한컴오피스에서 PDF로 다시 변환하고, 4~6쪽의 본문과 PDF 페이지 내용 스트림을 패키지의 신청서·결과보고서·별지 3쪽에 각각 대조했습니다. 배경 양식은 일치했습니다. 완성 PDF는 해당 배경에 입력값과 서명을 덧씁니다. 원본 한글 서식과 입력값 글꼴은 다를 수 있으며, 2027년 날짜의 연도와 가정학습 표기는 입력에 맞춰 조정합니다. 출력 형식은 PDF입니다.

## 검증 결과

- 로컬 Chrome에서 신청서·반일 신청서 PDF, 5일 보고서와 증빙을 합친 6쪽 PDF, 미리보기 및 브라우저 PDF 인쇄를 확인했습니다.
- 가상 명단으로 CSV·XLSX 가져오기, 31명 입력 제한, 웹 종속 드롭다운, 공통 값 복사, 30명 신청서 ZIP 생성을 확인했습니다. 테스트 중 외부 통신이나 작성 내용의 브라우저 저장이 발생하지 않았습니다.
- Microsoft Excel에서 2·16·31행의 세부목적 종속 유효성 검사와 공휴일 제외 일수, 누적·잔여일수, 마감일 계산을 확인했습니다.
- 이번 배포 패키지는 로컬에서 검증했습니다. GitHub Pages 게시 및 실물 프린터 테스트는 별도입니다.
